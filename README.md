# NESTED_CONSENSUS_ML
Two scripts for Google Colab. Script 1) performs leakage-safe preprocessing, consensus feature selection, nested cross-validation and hyperparameter tuning; compares six classifiers, derives thresholds, evaluates out-of-fold and holdout performance, assesses feature stability and importance, and saves the best frozen model. Script 2) predicts prospective patients using a frozen model.

Detailed instructions are provided in comments at the top of the script files.
